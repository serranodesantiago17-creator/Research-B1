# Audios del Student's Book (24 pistas)

Generados con Kokoro TTS (software libre, licencia Apache 2.0) a partir de los guiones de la guía del docente.
Cada personaje tiene una voz cercana a su acento; algunos acentos (nigeriano, ghanés, coreano, alemán, libanés,
australiano y neozelandés) son aproximados porque no existen voces libres específicas.

El sitio detecta estos archivos automáticamente. Para sustituir una pista por una grabación real, sube un mp3 con el mismo nombre.

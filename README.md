# Research Pathways B1 · Workbook interactivo

Actividades de práctica independiente del *Research Pathways B1 Workbook* (Posgrados UAZ), organizadas en 12 unidades como en el libro.

- **Retroalimentación inmediata:** al comprobar, cada respuesta incorrecta explica por qué y permite ver la respuesta correcta. Ya no hay clave de respuestas al final.
- **Escritura:** los ejercicios abiertos guardan el texto en el navegador, cuentan palabras e incluyen una lista de control y una respuesta modelo que se abre después de escribir.
- **Audios:** cada ejercicio *Listen again* tiene un espacio para su pista. Ver `audio/README.md`.
- **Imágenes:** fotografías de Wikimedia Commons (dominio público o licencias libres), con crédito en cada unidad.

## Estructura
```
index.html
css/styles.css
js/app.js               motor de ejercicios
js/data-units-1-6.js    contenido, unidades 1–6
js/data-units-7-12.js   contenido, unidades 7–12
js/audio-config.js      enlaces opcionales para los audios
audio/                  pistas .mp3
```
Los textos marcados como *written for this workbook* son ficticios y sirven para practicar.
